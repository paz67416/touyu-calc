# 灯油の日数・灯油代 計算機（お試し版）

石油ファンヒーターや石油ストーブの「燃料消費量（L/h）」と1日に使う時間、灯油の値段を入れると、1日の灯油の量、18Lのポリタンクが何日もつか、1か月の灯油代を出すページです。

- 使う：https://paz67416.github.io/touyu-calc/
- 完全版（機器4台まで・平日と休日の時間・ひと冬の合計とポリタンクの本数・給油と買い足しの予定・値段2つの差額・電気との比較・設定のURL保存）は note の記事で案内しています：https://note.com/chodo_lab/n/nfbf2c564f2fb

1枚のHTMLで動きます。入力した内容は保存も送信もしません。
